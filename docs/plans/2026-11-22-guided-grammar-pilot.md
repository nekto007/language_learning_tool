# Эталонная грамматика и обратная связь в практике

Согласовано 22 ноября 2026: небольшая порция теории → практика с конкретной
инструкцией → следующая порция. Подсказки A1–A2 доступны во время обычной
практики; итоговый тест модуля показывает проверку и объяснения после сдачи.

## Реализация

- [x] Авторский источник: `app/grammar_lab/content/plurals_demonstratives.json`.
  Восемь блоков, по три задания; сначала -s/-es, затем указательные слова,
  is/are, -y, четыре частых особых формы и смешанное применение.
- [x] У каждого задания указано действие и объём ответа. Расстояние до предмета
  задаётся явно; one/ones не мешает первому знакомству с темой.
- [x] Сохраняются ID темы, урока и всех прежних упражнений. Повторный импорт
  обновляет новые упражнения по стабильному guided_key, не создавая дубликаты.
- [x] Нативный урок поддерживает learning_steps. На планшете весь короткий блок
  виден вместе с примерами; крупный текст использует обычную прокрутку.
- [x] Проверка ответа до продолжения, объяснение ошибки и исправление того же
  вопроса. Первые ответы внутри попытки учитываются в результате отдельно от
  ответов после объяснения. Промежуточная проверка не выдаёт XP/SRS-прогресс.
- [x] После четырёх разных ошибок — обязательный разбор правил на границе
  маленького блока. Сетевые ошибки и повторные нажатия не считаются ошибками
  ученика. Затем продолжается практика с сохранённым прогрессом.
- [x] «Правило к заданию» использует явную авторскую связь. Когда её нет,
  доступна честно подписанная общая теория урока/модуля. Полный справочник
  открывается отдельно. Для остальных тем точные связи предстоит разметить.
- [x] Итоговый тест не открывает теорию и не вызывает промежуточную проверку.
- [x] Повтор урока получает новый токен сервера, очищает ответы, исправления,
  результаты проверок и прочитанные шаги. Завершённая попытка не берётся как
  новый документ урока из кэша.
- [x] Черновик сохраняет текущий ответ, первые ответы, объяснения и шаг чтения;
  смена аккаунта блокирует продолжение чужой сессии.

## Контент и окружение

Локальный импорт: `.venv/bin/python scripts/install_plurals_pilot.py --apply`.
Без `--apply` выводится только план. Скрипт допускает только loopback PostgreSQL
и перед применением сохраняет JSON исходной темы и уроков в `/tmp`.
Локально обновлены тема 4 и урок 58. Старые 104 упражнения сохранены;
24 новых составляют начальный нативный разбор. Исходный резервный файл:
`/tmp/llt-plurals-before-20261122T120548Z.json`.

Production не изменён. Для использования через сервер приложения нужны
публикация серверного кода и отдельный контролируемый импорт контента.
Не следует запускать локальный скрипт для production или удалённого хоста.

## Передача в Android

Пользователь поручил передать эти изменения в существующий Android-чат.
Реализовать тот же учебный сценарий нативно, с адаптацией для телефона,
планшета, крупного шрифта и восстановления после пересоздания Activity.
Серверные изменения уже находятся в общей рабочей папке; не дублировать
контент и оценщики в Kotlin, не переписывать сделанную iOS/backend работу.

Контракт:

- Документ урока: необязательные `learning_steps` и `immediate_feedback`.
  Шаг содержит `id`, `title`, `theory` (массив блоков title/body/kind),
  `question_ids` (упорядоченные строковые ID вопросов). Каждый вопрос
  содержит `instruction`; точечная справка — необязательный `theory_help`.
- Материал темы `GET /api/native/grammar/topics/{id}` содержит
  `guided_learning`: при true открывается практика с чередованием шагов,
  а не предварительное пролистывание всей теории.
- Проверка: `POST /api/native/lessons/{id}/check` либо
  `POST /api/native/activities/{kind}/check`. JSON:
  `{session_token, question_id, answer}`. Только Bearer.
  Ответ: `{success, feedback: {id, prompt, correct, answer, expected, explanation}}`.
  Это только обратная связь: XP, SRS и результат сохраняет обычный `/submit`.
- После неверного ответа показать объяснение и вернуть к тому же вопросу
  для исправления. Не переходить дальше, пока он не исправлен. Сохранить
  первый ответ внутри текущей попытки отдельно от исправленного; в `/submit`
  отправляются первые ответы, а не варианты после показа правильного ответа.
- После четырёх разных вопросов с ошибкой в первом ответе — короткий
  обязательный разбор на границе небольшого блока. Показывать только новые
  трудные правила после предыдущего разбора; сеть и повторные нажатия не
  увеличивают счётчик ошибок. Затем продолжить практику.
- На A1–A2 показывать «Правило к заданию» по явному `theory_help`.
  Если точной авторской связи пока нет — «Теория урока» с общей справкой.
  Введённый ответ и позиция не меняются при открытии/закрытии подсказки.
- `final_test` всегда исключение: нет промежуточной проверки и открытия
  теории во время попытки, даже если пришёл ошибочный флаг immediate_feedback.
  После сдачи показать результат и объяснения.
- «Повторить урок» получает НОВЫЙ серверный документ/токен, обнуляет текущие
  и первые ответы, проверки, счётчик ошибок, прочитанные шаги и старый result.
  Не использовать закэшированный токен завершённой попытки: иначе сервер
  вернёт receipt старого результата. Сохранение черновика прерванной попытки
  отличается от начала повтора; черновики изолированы по аккаунтам.
- Сбой проверки сохраняет ответ и даёт повторить запрос; 409 lesson_changed
  требует переоткрыть актуальную попытку. Отключение сети не считается
  учебной ошибкой и не даёт фиктивного правильного ответа.

Ориентиры: `ios/Core/Sources/LLTCore/CourseLesson.swift`,
`ios/LLT/Views/CourseLessonView.swift`, `app/grammar_lab/guided_learning.py`,
`app/api/native_lessons.py`, `app/api/native_activities.py`.
Проверить на Android: неправильный ответ → объяснение → исправление;
подсказку без потери ввода; блок после четырёх ошибок; прерывание и
восстановление; первый результат 50% → повтор с чистыми ответами → 100%;
отсутствие подсказки/мгновенной проверки в итоговом тесте; крупный шрифт
и поворот экрана. Проверки и сборку Android выполнять в Android-чате.
Production ещё не развёрнут — не маскировать отсутствие новых API под
успешную проверку; предусмотреть совместимость с отсутствующими полями.

## Следующее развитие эталона

После разбора ошибок отдельная пачка новых проверочных заданий на те же
слабые правила пока не выделена: продолжается авторская практика темы.
Распространять формат на остальные темы следует после просмотра эталона;
не переносить восемь блоков и порог ошибок механически на задания другой длины.
